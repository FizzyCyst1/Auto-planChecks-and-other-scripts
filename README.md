Export SunDose Profile Script will export profiles/PDD from a desired reference point in the plan into a text file that can be imported in SunDOSE. Must have restriction of 1 plan per field. Refer to word document for details. This was my first script ever and uses bits and pieces.

MergePDF is source code called using an excel macro. Once called it will merge all pdfs within a folder location, based on timestamp.
